# Dark Pool

Dark Pool is a multiplayer market-warfare game.

## Match shape
- 4 players
- 5 companies/assets
- 8 rounds

## Core fantasy
Players manipulate prices, narratives, and regulatory heat to outmaneuver rivals and finish with the strongest position.

## Round phases
1. News/Event
2. Secret Action Submission
3. Negotiation/Chat
4. Resolution
5. Disclosure/Public Update

## Supported actions
- buy
- short
- leak
- hype
- freeze_liquidity
- report_to_regulator
- acquire_stake

## Initial player archetypes
- activist_fund
- quant_predator
- shell_network
- media_syndicate
- distressed_debt
- regulatory_fixer

## MVP rules
- Highest net worth at end wins
- Server authoritative
- Private orders remain private until revealed by rules
- Public disclosures happen only during disclosure phase
