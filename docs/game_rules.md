# MVP game rules

## Players
4 players per match

## Companies
5 companies per match

## Rounds
8 rounds

## Phase 1: News/Event
A public event affects one or more companies.
Examples:
- earnings beat
- antitrust probe rumor
- supply shock
- executive scandal
- debt downgrade

## Phase 2: Secret Action Submission
Each player submits allowed actions for the round.
Actions are hidden until rules reveal outcomes.

## Phase 3: Negotiation
Timed public chat opens.
Optional whisper support can be added if authorized.

## Phase 4: Resolution
Server resolves actions in deterministic order:
1. event effects
2. liquidity adjustments
3. price movements
4. leaks/hype
5. stake acquisition
6. regulatory heat
7. margin stress / forced effects
8. end-of-round state updates

## Phase 5: Disclosure
Only authorized public information is broadcast.

## Win condition
Highest net worth after round 8.
